Shaale Vikas: Transparent School Infrastructure Crowdfunding 🏫
Shaale Vikas is a high-performance Android application designed to bridge the transparency gap between NGOs and donors. This project replaces traditional, paper-based tracking with a decentralized digital ledger, ensuring every contribution towards school infrastructure is visible and verifiable in real-time.

🌟 Key Innovations
1. Real-Time Transparency Engine
Utilizing Cloud Firestore, the app features a "Pledge-and-Track" system. Whenever a donor makes a pledge, the funding progress bar for that specific infrastructure "Hero Item" updates instantly across all devices globally.

2. GenAI Support Integration
Integrated with the Gemini AI SDK, the platform includes a specialized support bot. This AI acts as a 24/7 virtual assistant, handling complex donor FAQs regarding school needs, tax benefits, and project timelines, reducing administrative overhead for NGOs.

3. "Premium Business" UI/UX
Built entirely with Jetpack Compose (Material 3). The design language focuses on trust and professional appeal, featuring:

Dynamic state-driven animations.
Custom surface elevations and premium shadow effects.
Responsive layouts for varied Android screen sizes.
🛠️ Technical Architecture (MVVM)
The project follows the Model-View-ViewModel (MVVM) architecture to ensure clean code separation and scalability:

View (Jetpack Compose): Handles the UI and user interactions.
ViewModel: Manages the UI state and acts as a bridge between Firestore and the UI.
Model (Firebase): Real-time NoSQL data storage and secure Authentication.
🚀 Tech Stack
Language: Kotlin (Modern, Null-safe)
Framework: Jetpack Compose (Declarative UI)
Database: Firebase Cloud Firestore (Real-time sync)
Auth: Firebase Google Authentication
AI Engine: Google Generative AI (Gemini Pro)
Media: Coil Library (Async Image Loading)
📦 How to Build & Run
Clone the Repo:

git clone https://github.com
Setup Firebase:

Add your google-services.json file to the app/ directory.

API Keys:

Insert your Gemini API Key in the local.properties or respective configuration file.

Build:

Open in Android Studio (Ladybug or later) and click Run.
